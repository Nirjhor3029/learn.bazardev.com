# Chapter 6 — Task 2: The Five Essay Question Types

> **Course:** IELTS Writing · **Chapter:** 6 of 12
> Read on the website: [learn.bazardev.com/ielts-writing/06-task2-the-five-question-types](https://learn.bazardev.com/ielts-writing/06-task2-the-five-question-types)

Misreading the question type is the single biggest cause of a low Task Response score — you can write a beautifully organised, grammatically perfect essay that still scores poorly because it answers the *wrong* question. Before you plan anything, identify which of five types you're facing.

## 2. What each type actually demands

| Type | What you must do |
|---|---|
| **Opinion** | Take a clear position and keep it consistent throughout — fully agree, fully disagree, or a partial stance you still argue for clearly. |
| **Discussion** | Present **both** sides fairly and in balance, **then** give your own opinion — skipping the opinion loses marks even if both sides are well-argued. |
| **Problem-solution** | Clearly name the problems, then propose realistic, specific solutions — vague solutions ("the government should do something") score poorly. |
| **Advantage-disadvantage** | Cover both sides with reasonable balance; only add a personal opinion if the prompt explicitly asks for one. |
| **Two-part** | Answer **both** questions directly, usually with roughly one body paragraph per question. |

## 4. Common mistakes to fix

| ❌ Wrong | ✅ Correct |
|---|---|
| For a "discuss both views" prompt, the essay only argues the writer's opinion. | Present **both** views fairly, in separate paragraphs, then give your opinion. |
| For an advantage/disadvantage prompt with no opinion request, the writer adds a strong personal opinion anyway. | Stick to a balanced overview of advantages and disadvantages unless asked for an opinion. |
| A two-part question ("Why...? What can be done...?") only answers the first question. | Answer **both** questions — one paragraph for each is a safe structure. |
| A problem-solution essay proposes vague solutions like "people should be more careful." | Propose **specific, realistic** solutions — e.g., "stricter fines" or "mandatory safety training." |

## 5. Quick practice

<details>
<summary><strong>Q1. "Discuss both views and give your opinion" — which type is this?</strong></summary>

**Discussion.** It requires both sides presented, plus a personal opinion.
</details>

<details>
<summary><strong>Q2. A prompt asks "Why do you think this is happening? What measures could be taken to address it?" — which type?</strong></summary>

**Two-part (direct question).** Both questions need a direct answer.
</details>

<details>
<summary><strong>Q3. In a discussion essay, if you only argue your own opinion and ignore the opposing view, what happens?</strong></summary>

**You lose marks on Task Response** — the task specifically requires both views to be discussed.
</details>

<details>
<summary><strong>Q4. Does an advantage-disadvantage essay always need your personal opinion?</strong></summary>

**No** — only if the prompt explicitly asks for one. Otherwise, keep it balanced and objective.
</details>
