# Chapter 3 — Matching Headings

> **Course:** IELTS Reading · **Chapter:** 3 of 12
> Read on the website: [learn.bazardev.com/ielts-reading/03-matching-headings](https://learn.bazardev.com/ielts-reading/03-matching-headings)

Matching headings is the one question type that rewards **skimming** over scanning (Chapter 1) — you're identifying each paragraph's overall point, not hunting for a specific detail.

## 1. The core rule: main idea, not a detail

A heading must summarise the **whole paragraph**, not one fact mentioned inside it. There are always **more headings than paragraphs**, so some headings are deliberately left unused — these extra, tempting-but-wrong options are called **distractors**.

The main idea is usually in the paragraph's **first or last sentence**, though occasionally it only becomes clear by the second or third sentence — skim the whole paragraph rather than stopping too early.

## 3. Common mistakes to fix

| ❌ Wrong | ✅ Correct |
|---|---|
| Choosing a heading because it shares a keyword with the paragraph. | Shared vocabulary isn't proof — check whether the heading matches the paragraph's **overall** point. |
| Reading every sentence in full detail, slowly. | Skim for structure and gist; save close reading for headings that look very similar to each other. |
| Reusing a heading for two different paragraphs. | Each heading is typically used **once** — cross one off as soon as you use it. |
| Getting stuck on one hard paragraph and running out of time. | If two headings look equally good, note both and move on — come back if time allows. |

## 4. Quick practice

<details>
<summary><strong>Q1. A heading mentions one specific fact that also appears in the paragraph. Is that enough to confirm it's correct?</strong></summary>

**No** — a heading must match the paragraph's overall main idea, not just one detail.
</details>

<details>
<summary><strong>Q2. Where is a paragraph's main idea usually found?</strong></summary>

**In the first or last sentence** — though sometimes it only becomes clear a bit later.
</details>

<details>
<summary><strong>Q3. Why are there always more headings than paragraphs?</strong></summary>

**To create distractors** — tempting but incorrect options that test whether you've truly identified the main idea.
</details>

<details>
<summary><strong>Q4. Should you read every word of every paragraph closely for this question type?</strong></summary>

**No** — skim for the gist; this question type rewards skimming over detailed, slow reading.
</details>
