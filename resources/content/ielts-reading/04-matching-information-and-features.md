This chapter covers two closely related question types that both reverse Chapter 3's logic: instead of finding a paragraph's *main idea*, you're hunting for a *specific detail*, wherever it happens to appear.

Matching information is generally considered **harder** than matching headings, since the target detail might be a small fact buried mid-paragraph, not the paragraph's main point.

## 2. Two important rules that differ from Chapter 3

- **The order of the questions does NOT follow the order of the passage.** You may need to jump between paragraphs — don't assume question 1's answer comes before question 2's.
- **A paragraph can be the correct answer more than once** (always check the instructions — unlike matching headings, where each heading is usually used once, a paragraph letter in matching information can repeat).

## 3. Matching features: names, theories, and categories

A related type gives a list of named people, theories, or categories (A, B, C...) and asks you to match statements to the correct one.

## 4. Common mistakes to fix

| ❌ Wrong | ✅ Correct |
|---|---|
| Looking for a paragraph's overall theme, like in matching headings. | Look for the **specific detail** named in the statement — it could be a minor point. |
| Assuming the answers follow the passage's order. | Scan the **whole** passage for each statement; the order isn't fixed. |
| Assuming each paragraph/name can only be used once. | Check the instructions — a letter can sometimes be used **more than once**. |
| Matching based on a shared name alone, ignoring what's actually claimed. | Read **around** the name carefully — a passage can mention a name without attributing the specific claim in the question to them. |

## 5. Quick practice

<details>
<summary><strong>Q1. Does matching information test a paragraph's main idea, like matching headings?</strong></summary>

**No** — it tests a specific detail, which could be anywhere in the passage.
</details>

<details>
<summary><strong>Q2. Do the questions in a matching information task follow the passage's order?</strong></summary>

**No** — you may need to jump between paragraphs; the order isn't fixed.
</details>

<details>
<summary><strong>Q3. What's the first step for a matching features question about named researchers?</strong></summary>

**Underline every name as it appears in the passage**, then read around each one.
</details>

<details>
<summary><strong>Q4. Do statements in matching information/features questions usually repeat the passage's exact wording?</strong></summary>

**No** — they're almost always paraphrased, so recognising synonyms matters.
</details>
