# Chapter 5 — Matching

> **Course:** IELTS Listening · **Chapter:** 5 of 12
> Read on the website: [learn.bazardev.com/ielts-listening/05-matching](https://learn.bazardev.com/ielts-listening/05-matching)

Matching links items you hear in the recording — people, places, activities, opinions — to a fixed list of options printed on the question paper. It tests whether you can follow a conversation and connect facts to each other, often across several speakers.

## 1. Always check the instructions first

Some matching tasks let you use the same option **more than once**; others use each option exactly once, leaving some unused. This varies task to task — always read the instructions before you assume either way.

Weaker candidates listen for the same words printed in the options; stronger candidates recognise when the recording **paraphrases** an option's meaning. This is the exact same paraphrase-recognition skill from Reading — applied to speech instead of text.

## 3. The options rarely appear in the audio in their printed order

Unlike table completion, matching options are often discussed in a different order than they're listed on paper. Read all the options first, then track them actively as speakers talk — don't assume the first item you confirm is "A."

## 4. Eliminate as you go

Once you're confident an option matches an item, mentally cross it off (if each option is used once) — this narrows your remaining choices for the items still unmatched, especially useful near the end of a tricky section.

## 5. Common mistakes to fix

| ❌ Wrong | ✅ Correct |
|---|---|
| Assuming every matching task allows repeated options. | Check the instructions each time — this varies by task. |
| Listening for the exact words printed in the options. | Listen for paraphrase — the recording rarely repeats the option's wording directly. |
| Assuming options are discussed in their printed order. | Track all options actively; the audio order can differ from the printed order. |
| Forgetting to eliminate confirmed matches. | Cross off matched options (where applicable) to narrow down what's left. |

## 6. Quick practice

<details>
<summary><strong>Q1. Should you assume a matching task allows you to reuse the same option twice?</strong></summary>

**No** — always check the instructions, since this varies from task to task.
</details>

<details>
<summary><strong>Q2. The audio says "Tom just couldn't get behind the idea," and an option reads "disagreed with the plan." What's happening?</strong></summary>

**Paraphrase** — the same meaning, expressed with different words, same skill as Reading.
</details>

<details>
<summary><strong>Q3. Do matching options usually appear in the audio in the same order they're printed?</strong></summary>

**Not necessarily** — track all the options actively rather than assuming the printed order matches the audio order.
</details>

<details>
<summary><strong>Q4. What should you do once you're confident about a match?</strong></summary>

**Mentally eliminate that option** (where the task allows one use each) to narrow down the remaining choices.
</details>
